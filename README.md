# OS4P26-arduino-sensor-group10
Low-cost CO₂ and P/T/RH logger with Arduino Uno – OS4P reproducibility challenge

Components
  -CO_2 sensor
  -External Battery (laptop)
  -Arduino
  -Sd card + Sd card reader
  -Breadboard
  -Cables

1. To start download the arduino software here https://www.arduino.cc/en/software/. Make sure to change the software download to accomodate your windows version (or other operating system)    
2. Copy the code from this github to your software
3. Follow the schematic to connect the different componets (add picture)
4. Connect the arduino to your laptop and run the code on the arduino software
6. Measure the CO_2 and (How will we analyze the data and make plot or it that not necessary)
